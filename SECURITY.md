# Security Policy

## Reporting a suspected security vulnerability

If you believe you have found a security vulnerability in this app, report it through the Morse Micro security-disclosure form:

https://www.morsemicro.com/policy/security-disclosure

Do not post vulnerability details in a public GitHub Issue, pull request, or discussion. Public reports can put other users at risk before a fix is available.

When you submit the form, include:

- the app version (shown on the app's Info page in Home Assistant),
- your Home Assistant Operating System version,
- a description of the issue and the steps that reproduce it.

Do not include your Wi-Fi passphrase or other secrets in a report.

## Support and defects

For questions, defects, and feature requests that are not security vulnerabilities, open an issue in [GitHub Issues](https://github.com/MorseMicroLabs/home-assistant-halow/issues). GitHub Issues are public, so remove or mask device MAC and IP addresses from any diagnostics before you post them.

## Supported versions

Security fixes are made in the latest released version of the app. Update to the latest version through Home Assistant.
